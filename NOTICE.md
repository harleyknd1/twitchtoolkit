## Project Lineage

This project is based on the mod "TwitchStories," originally created by Finally.

It was later forked and significantly modified by hodlhodl to create Twitch Toolkit,
a distinct and independently developed mod for RimWorld.

The project is currently maintained by the Toolkit Community.
